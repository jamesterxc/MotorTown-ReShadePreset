Required In‑Game Brightness Setting[/h2]

For the preset to work correctly, you must set the in‑game brightness to:

[b]Settings → Display → Brightness → 100[/b]

Motor Town’s exposure system is tied directly to the brightness slider.  
Setting brightness to 100 prevents the extreme exposure jumps that cause daytime glare and nighttime darkness.

Note:  
The main menu and loading screens may look washed out or have odd colors.  
This is normal.  
Once you are in gameplay, lighting will be stable and the preset will prevent the “flashbang” effect the base game normally produces at random.
